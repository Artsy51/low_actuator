## 3. 64-bit 力位混控

```text
mode[3] | KP[12] | KD[9] | qpos[16] | qvel[12] | qtor[12]
```

位位置：

```text
mode : [63:61]
KP   : [60:49]
KD   : [48:40]
qpos : [39:24]
qvel : [23:12]
qtor : [11:0]
```

```c
uint64_t word64 =
    ((uint64_t)(mode & 0x07) << 61) |
    ((uint64_t)(kp   & 0x0FFF) << 49) |
    ((uint64_t)(kd   & 0x01FF) << 40) |
    ((uint64_t)(pos  & 0xFFFF) << 24) |
    ((uint64_t)(vel  & 0x0FFF) << 12) |
    ((uint64_t)(tor  & 0x0FFF));

for (int i=0; i<8; ++i)
    data[i] = (word64 >> (56-8*i)) & 0xFF;
```

公开手册说明数据区采用高位先、低位后存储。

## 5. CAN Identifier

### Q&A

```text
Control ID = Motor ID
Setting/Query ID = 0x7FF
```

### 自动消息

```text
Feedback ID = 0x204 + MotorID
```

例：`Motor ID 1 -> 0x205`。

分组电流命令：`0x1FF` 控制 ID 1~4，`0x2FF` 控制 ID 5~8。

## 6. Q&A Type 1 反馈

```text
Message class : 0x01
Error         : 5 bit
Position      : 16 bit, -12.5~+12.5 rad
Speed         : 12 bit, -18~+18 rad/s
Current       : 12 bit, -60~+60 A（EC 系列公开范围表）
Motor Temp    : uint8, raw=T×2+50
MOS Temp      : uint8, raw=T×2+50
```

## 7. 设置/查询命令

### 设置通信模式

```text
ID=0x7FF, DLC=4
[MotorID_H, MotorID_L, 0x00, 0x01]  # 自动消息
[MotorID_H, MotorID_L, 0x00, 0x02]  # Q&A
```

### 当前位置置零

```text
ID=0x7FF, DLC=4
[MotorID_H, MotorID_L, 0x00, 0x03]
```

### 修改 Motor ID

```text
ID=0x7FF, DLC=6
[OldID_H, OldID_L, 0x00, 0x04, NewID_H, NewID_L]
```

### 恢复 ID=1

```text
ID=0x7FF, DLC=6
[0x7F,0x7F,0x00,0x05,0x7F,0x7F]
```

## 8. 温度和错误码

```text
T(°C) = (raw_temp - 50) / 2
```

| Code | 含义 |
|---:|---|
| 0 | 无错误 |
| 1 | 电机过温 |
| 2 | 电机过流 |
| 3 | 电压过低 |
| 4 | 编码器错误 |
| 6 | 抱闸电压过高 |
| 7 | DRV 错误 |

## 9. 版本差异

当前 ENCOS 产品分类页（2026-09-09 更新）列出：19 N·m 额定扭矩、90 N·m 峰值扭矩、150 rpm 峰值转速、868 g；公开旧版 RMD-X8-P18-90 手册则给出 30 N·m 额定扭矩、145 rpm 峰值转速、830 g。建议根据实际采购批次、固件和标签确认。
