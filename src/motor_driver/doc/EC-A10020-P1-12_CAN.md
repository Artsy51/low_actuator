## 3. 力位混控 CAN 控制帧

64-bit 位域：

```text
mode[3] | KP[12] | KD[9] | qpos[16] | qvel[12] | qtor[12]
```

位位置：

```text
mode : [63:61]
KP   : [60:49]
KD   : [48:40]
qpos : [39:24]
qvel : [23:12]
qtor : [11:0]
```

打包：

```c
uint64_t word64 =
    ((uint64_t)(mode & 0x07) << 61) |
    ((uint64_t)(kp   & 0x0FFF) << 49) |
    ((uint64_t)(kd   & 0x01FF) << 40) |
    ((uint64_t)(pos  & 0xFFFF) << 24) |
    ((uint64_t)(vel  & 0x0FFF) << 12) |
    ((uint64_t)(tor  & 0x0FFF));

for (int i = 0; i < 8; ++i)
    data[i] = (word64 >> (56 - 8*i)) & 0xFF;
```

公开手册说明控制数据采用高位先、低位后存储。

## 4. 本型号协议量程

| 信号 | 位宽 | 原始范围 | 物理范围 | 解码 |
|---|---:|---:|---:|---|
| KP | 12 bit | 0~4095 | 0~500 | `kp=raw/4095×500` |
| KD | 9 bit | 0~511 | 0~5 | `kd=raw/511×5` |
| qpos | 16 bit | 0~65535 | -12.5~+12.5 rad | `pos=-12.5+raw/65535×25` |
| qvel | 12 bit | 0~4095 | -18~+18 rad/s | `vel=-18+raw/4095×36` |
| qtor | 12 bit | 0~4095 | -150~+150 N·m | `tor=-150+raw/4095×300` |
| CAN 电流量程 | 12 bit | 0~4095 | -70~+70 A | EC 系列公开协议表 |

通用公式：

```text
raw = round((x-xmin)/(xmax-xmin) × (2^N-1))
x   = xmin + raw/(2^N-1) × (xmax-xmin)
```

## 5. CAN Identifier

### Q&A 模式

```text
Control CAN ID   = Motor ID
Setting/Query ID = 0x7FF
```

### 自动消息模式

```text
Feedback CAN ID = 0x204 + MotorID
```

例：`ID=1 -> 0x205`，`ID=2 -> 0x206`，`ID=5 -> 0x209`。

分组电流控制：

```text
0x1FF -> Motor ID 1~4
0x2FF -> Motor ID 5~8
```

## 6. Q&A Type 1 反馈

| 字段 | 位宽 | 说明 |
|---|---:|---|
| Message class | 3 | `0x01` |
| Error | 5 | 公开错误码 0~7 |
| Position | 16 | -12.5~+12.5 rad |
| Speed | 12 | -18~+18 rad/s |
| Actual current | 12 | 型号相关 |
| Motor temperature | 8 | `raw=T×2+50` |
| MOS temperature | 8 | `raw=T×2+50` |

温度反解：`T=(raw-50)/2`。

## 7. 错误码

| Code | 含义 |
|---:|---|
| 0 | 无错误 |
| 1 | 电机过温 |
| 2 | 电机过流 |
| 3 | 电机电压过低 |
| 4 | 电机编码器错误 |
| 6 | 电机抱闸电压过高 |
| 7 | DRV 驱动错误 |

## 8. 常用设置命令

### 设置通信模式

CAN ID=`0x7FF`，DLC=4：

```text
[MotorID_H, MotorID_L, 0x00, 0x01]  # 自动消息模式
[MotorID_H, MotorID_L, 0x00, 0x02]  # Q&A 模式
```

### 当前位置置零

```text
CAN ID=0x7FF
DLC=4
[MotorID_H, MotorID_L, 0x00, 0x03]
```

### 修改 Motor ID

```text
CAN ID=0x7FF
DLC=6
[OldID_H, OldID_L, 0x00, 0x04, NewID_H, NewID_L]
```

### ID 恢复为 1

```text
CAN ID=0x7FF
DLC=6
[0x7F, 0x7F, 0x00, 0x05, 0x7F, 0x7F]
```

## 9. 调试建议

1. 首次只连接一个节点。
2. CAN 初始化为 1 Mbps、标准帧。
3. 先确认 Motor ID 和反馈。
4. 首次运动使用小位置、小速度、小力矩。
5. 参数设置类命令之间至少间隔 500 ms。
6. 保存原始 TX/RX 帧，用实机验证字节序。

## 10. 版本差异

当前 ENCOS 产品分类页（2026-09-09 更新）列出额定扭矩 48 N·m；此前公开资料存在 50 N·m 的旧值。因此项目应以实际采购批次和厂家协议版本为准。
