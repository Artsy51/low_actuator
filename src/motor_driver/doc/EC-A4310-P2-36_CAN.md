## 3. 64-bit 力位混控

```text
mode[3] | KP[12] | KD[9] | qpos[16] | qvel[12] | qtor[12]
```

位位置：

```text
mode : [63:61]
KP   : [60:49]
KD   : [48:40]
qpos : [39:24]
qvel : [23:12]
qtor : [11:0]
```

```c
uint64_t word64 =
    ((uint64_t)(mode & 0x07) << 61) |
    ((uint64_t)(kp   & 0x0FFF) << 49) |
    ((uint64_t)(kd   & 0x01FF) << 40) |
    ((uint64_t)(pos  & 0xFFFF) << 24) |
    ((uint64_t)(vel  & 0x0FFF) << 12) |
    ((uint64_t)(tor  & 0x0FFF));

for (int i=0; i<8; ++i)
    data[i] = (word64 >> (56-8*i)) & 0xFF;
```

## 5. CAN Identifier

### Q&A

```text
Control ID = Motor ID
Setting/Query ID = 0x7FF
```

### 自动消息

```text
Feedback ID = 0x204 + MotorID
```

例：`Motor ID 1 -> 0x205`。

分组电流命令：`0x1FF` 控制 ID 1~4，`0x2FF` 控制 ID 5~8。

## 6. Q&A Type 1 反馈

```text
Message class : 0x01 (3 bit)
Error         : 5 bit
Position      : 16 bit, -12.5~+12.5 rad
Speed         : 12 bit, -18~+18 rad/s
Current       : 12 bit, -30~+30 A
Motor Temp    : uint8, raw=T×2+50
MOS Temp      : uint8, raw=T×2+50
```

## 7. 常用命令

### 设置通信模式

```text
ID=0x7FF, DLC=4
[MotorID_H, MotorID_L, 0x00, 0x01]  # 自动消息
[MotorID_H, MotorID_L, 0x00, 0x02]  # Q&A
```

### 当前位置置零

```text
ID=0x7FF, DLC=4
[MotorID_H, MotorID_L, 0x00, 0x03]
```

### 修改 ID

```text
ID=0x7FF, DLC=6
[OldID_H, OldID_L, 0x00, 0x04, NewID_H, NewID_L]
```

### 恢复 ID=1

```text
ID=0x7FF, DLC=6
[0x7F,0x7F,0x00,0x05,0x7F,0x7F]
```

T(°C) = (raw_temp - 50) / 2

## 9. 重要调试信息

- CAN 控制和 USB 控制不应作为两个独立控制源同时操作；公开手册说明 CAN 优先，但 USB 控制不能完全屏蔽。
- 设置通信模式、清零和修改 ID 的命令之间至少等待 500 ms。
- 置零失败可能发生在电机运行中、上一命令未完成或已有报警时。
- 电流/力矩模式下电机只要旋转就会继续加速，因此首次调试要格外谨慎。
